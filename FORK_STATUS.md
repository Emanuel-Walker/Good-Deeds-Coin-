# Repository status

## Plain English

This is a **historical learning fork** of the ConsenSys `Tokens` repository.

Upstream:

```text
https://github.com/ConsenSys/Tokens
```

The package metadata, authors, badges, and contract implementation come from that upstream project.

I am keeping this repository for history and learning context.

I do **not** present it as an original current project.

## Technology age

The upstream README says the guaranteed environment was:

```text
Node 8
```

The package uses older Truffle-era dependencies.

Treat it as historical Solidity/EIP-20 study material, not as a modern production starter.

## Safe learning path

If you are studying this repository:

1. Read the upstream README.
2. Inspect `contracts/`.
3. Inspect `test/`.
4. Run the historical test suite only in an isolated development environment.
5. Do not deploy these contracts to a live network just because the tests pass.
